# Ministry of Health - Business Central Extension

This is a Microsoft Dynamics 365 Business Central AL extension for the **Ministry of Health**.

## Overview

This extension provides functionality to manage health facility records, patient registrations, and health service tracking within Microsoft Dynamics 365 Business Central.

## Features

- **Health Facility Management** – Register and manage health facilities (hospitals, clinics, health centres).
- **Patient Registration** – Record and maintain patient demographic and contact information.
- **Health Service Tracking** – Log health services rendered to patients at registered facilities.

## Requirements

- Microsoft Dynamics 365 Business Central (on-premises or cloud)
- AL Language extension for Visual Studio Code

## Getting Started

1. Open the project folder in Visual Studio Code with the AL Language extension installed.
2. Configure `.vscode/launch.json` to point to your Business Central instance.
3. Press **F5** to publish the extension to your sandbox environment.
